# Direction-Aware Fitness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make outbound and inbound traffic unambiguous and visible to the existing multiscale similarity score.

**Architecture:** Capture only non-promiscuous target `eth0`, persist its MAC in a small `capture.json`, and use that metadata to classify reference and generated Ethernet frames. Extend the existing multiscale packet/byte vectors with a direction dimension; do not add a method, model interface, weight, or experiment setting.

**Tech Stack:** Markdown architecture documents, Docker Compose capture contract, PCAPNG Ethernet frames, normalized L1 similarity

## Global Constraints

- Capture only the target container's `eth0` with promiscuous mode disabled.
- Classify a frame as `outbound` when its source MAC equals the target MAC; classify every other valid frame captured on non-promiscuous `eth0` as `inbound`.
- Persist exactly `interface` and `target_mac` in `capture.json`; reject unknown or invalid fields.
- Use the same target MAC and a deterministic distinct peer MAC when rendering generated PCAPNG.
- Keep exactly four MVP similarity methods.
- Keep existing method, packet/byte feature, and scale weights.
- Flatten outbound bins followed by inbound bins for each multiscale feature.
- Require `2 * sum(B_h) <= maximum_total_bin_count`.
- Treat shared capture metadata and parsing failures as stage errors, never candidate fitness `0`.
- Do not address observation windows, background processes, genetic operators, or other audit findings in this fix.

In `multiscale_rate.md`, retain the current time alignment and bins. For each

```text

```

Write the mathematical form exactly:

```latex
r_{h,f}=(r_{out,1},\ldots,r_{out,B},r_{in,1},\ldots,r_{in,B}).
```

Packet cells count events; byte cells sum captured frame lengths. Keep the
existing normalized L1, zero-denominator, feature-weight, scale-weight, and
`1 - D` equations unchanged.

- [ ] **Step 2: Correct bounds, diagnostics, and cost**

Define the existing maximum-total-bin setting as a direction-cell cap:

```latex
2\sum_h B_h\le C_{max}.
```

Diagnostics report outbound and inbound packet/byte totals per scale plus the
combined feature discrepancies. Replace the ambiguous width-count notation in
the cost section with `W` for the configured width set:

```latex
O(|W|(n+m)+C_{max})
```

and retain `O(C_max)` storage.

- [ ] **Step 3: Add exact direction examples**

Add hand-checkable examples:

```text

generated packet vector = [0, 1]  # zero outbound, one inbound

```

Also require identical direction-bin vectors to score `1`, mixed differences to
affect only their changed cells, and exact direction symmetry to remain
indistinguishable.
